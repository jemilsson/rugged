## How the keys were generated

`solana-cli` has no binary substituter hit on this machine and compiles from
source under `nix shell nixpkgs#solana-cli` (20-40+ min, confirmed still
compiling after two full invocations). `scripts/devnet-prep.sh` auto-detects
a missing `solana`/`solana-keygen` and falls back to
`scripts/pysolkeygen.py`, a pure-stdlib Ed25519 keygen (RFC 8032 reference
algorithm; correctness checked with a sign/verify round-trip, not just a
memorized test vector) that writes the identical
`[seed(32 bytes) || pubkey(32 bytes)]` JSON keyfile format `solana-keygen`
uses. Airdrop and balance calls go through direct JSON-RPC (`curl`) to
`https://api.devnet.solana.com` in that mode. Once the Nix-built `solana`
CLI is available, re-running the script is a no-op for the already-generated
keys and switches back to the CLI path for airdrop/balance automatically.
